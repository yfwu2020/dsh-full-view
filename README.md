# 完整视图 · 悬浮聊天

**把空间留给文件和网页，同时继续和 Agent 对话。**

这是 DeepSeek Harness 的界面插件。点击右侧文件或浏览器面板的「全屏」，工作内容展开到主工作区，当前聊天变成右下角的紧凑输入条。点击输入条外缘，即可展开聊天小窗。你可以一边看预览、一边继续发消息；退出全屏后，聊天回到原来的分栏位置。

[下载安装包](https://github.com/yfwu2020/dsh-full-view/releases/latest) · [报告问题](https://github.com/yfwu2020/dsh-full-view/issues) · [更新记录](#更新记录)

![完整视图：网页占据主工作区，原聊天保留在右下角小窗中](https://raw.githubusercontent.com/yfwu2020/dsh-full-view/main/docs/images/full-view.jpg)

> 本文配图均为 DeepSeek Harness 实际界面截图。主分支新增交互一节的局部截图来自当前 macOS Desktop 实测；其余分栏与完整视图图片来自 0.1.1，使用公开示例网页，并收起左侧导航。0.1.4 默认显示紧凑输入条，旧图中的标题栏收起状态已被输入条替代。

## 它能做什么

- **展开工作内容**：让右侧文件、编辑器或网页预览获得更大的显示空间。
- **继续原来的对话**：小窗使用当前会话，保留消息、输入草稿和宿主的聊天操作。
- **移动与调整大小**：拖动输入条外缘或展开后的标题栏移动，展开后拖动右下角调整尺寸。
- **临时收起聊天**：收成紧凑输入条，仍可输入和发送；点击外缘展开聊天。
- **一键回到分栏**：聊天、文件和网页继续使用原来的内容实例。

这个插件只改变完整视图中的呈现方式。左侧导航栏的展开与收起仍由 Harness 管理。

## 主分支新增交互（尚未发布）

以下改动已提交到 `main`，**npm 和 GitHub Release 的最新版本仍是 0.1.4**。通过现有本地仓库链接或源码安装才能使用本段功能。本文其余安装示例和真实截图仍对应已发布版本，不将开发验证页当作桌面截图。

- 完整视图中隐藏 `dsh-selection-explain` 的常驻胶囊和悬浮球，避免与鲸鱼球重叠；划词解读 / 引用按钮及解读小窗仍可使用，退出后胶囊恢复。
- 打开解读小窗、点击正文或输入追问，聊天小窗保持展开；关闭解读也不会联动收起聊天。官方共享浮层仍在工作面板和聊天小窗上方，空白区域可操作网页。
- 完整小窗标题右侧的图钉可固定展开。图钉高亮时，点击空白、侧栏或网页不会收起聊天，再点一次解除固定。「−」、外缘、Esc 和返回分栏仍可手动操作；退出完整视图或切换会话后清除固定。
- macOS 下完整视图的首列标签栏取消多余窗口控件留白，标签从工作区左侧正常排列；普通分栏不受影响。
- 输入框获得焦点时直接展开完整聊天小窗，包含消息、标题和操作栏；没有只展开标题栏的中间模式。点击工作内容或在聊天里按 Esc 收回简洁输入条，鼠标悬停不会展开。
- 点击紧凑输入条上边缘中间的小横条，可主动收成鲸鱼球；不占输入区宽度，没有悬停文字。展开小窗后横条隐藏，继续使用标题栏「−」。等待回应或输入法组词时暂停这个入口。
- 紧凑输入条默认闲置 **90 秒（1 分 30 秒）**后自动收成鲸鱼尾巴小球；在输入条上移动鼠标、点击、输入或滚动会重新计时。菜单打开、拖动、中文输入法组合和待办确认期间暂停回收；展开的完整小窗不自动隐藏。
- 标题与标题栏空白用于拖动小窗，单击不再切换形态。点击外缘查看完整聊天；点击工作内容或在聊天里按 Esc 收回输入条。原生菜单打开和中文输入法组合过程中不会误收起。
- 点击左上角「−」隐藏整个小窗，只保留无文字的鲸鱼尾巴小球；点击小球直接恢复完整小窗、原草稿和输入焦点，小球也可拖动。
- 输入条统一圆角，模型入口使用脑形图标；点击仍打开 Harness 原有的模型与推理等级菜单。
- 输入框底部的轮数、步数、速度、token、缓存和上下文统计，在完整视图中始终隐藏；回到普通分栏后恢复宿主显示。
- 添加的附件保持在输入框上方，紧凑条、完整小窗和窄窗口都遵循原有排列；删除附件后恢复紧凑高度。
- 小窗内的聊天和长草稿滚动条隐藏，保留滚动能力；取消滚动条预留宽度，紧凑条与完整小窗之间切换时输入框不再横向挪动。
- 完整小窗和紧凑条收成鲸鱼球时使用「连续缩入」：内容先淡出，外框向右下角缩成球，鱼尾在末段出现；点击球反向恢复。原文字不被压缩或重新换行，中途也可恢复。系统启用“减少动态效果”时直接切换。
- 紧凑状态可拖动左右边调整宽度；展开后可拖动四边和四角缩放。靠近工作区边缘松手会吸附；拖动时按 Esc 取消。角落保持没有角标，双击仍可恢复默认尺寸。
- 运行时在输入框的占位文字位置显示“已处理 23 秒”等真实回合耗时，与按钮同一行，不增加输入条高度。输入草稿时优先显示草稿；不再弹出“有新内容 · 查看”。如果宿主暂未提供开始时间，显示“处理中…”。
- 隐藏后的鲸鱼尾巴使用 Harness 思考时自带的图标和动画；空闲、完成或等待确认时使用 DSH 原生 SVG 静止图，避免高分屏放大动画首帧导致模糊。鱼尾右上角加上与工作区标题一致的状态点：运行时只播放鱼尾动画，不显示小点，完成且未查看时为成功色（通常绿色），点开会话后消失，需要回答、审批或确认计划为提醒色（通常橙色），空闲为宿主空闲色。已收成鲸鱼球时，待办保持球形提醒；点击球展开原待办。紧凑条出现待办仍自动展开，处理后回到之前的形态。
- 窄窗口改用两行输入排列，保留附件、权限、模型和发送按钮。支持键盘移动 / 缩放和系统减少动态效果设置。

## 安装

### 通过 Harness 插件管理页安装

1. 打开 Harness 左侧的 **插件** 页面，点击 **添加插件**。
2. 填写 npm 包名，完成安装：

   ```text
   @yfwu2020/dsh-full-view
   ```

   需要固定版本时填写 `@yfwu2020/dsh-full-view@0.1.4`。也可以使用 GitHub 上的 0.1.4 安装包地址：

   ```text
   https://github.com/yfwu2020/dsh-full-view/releases/download/v0.1.4/yfwu2020-dsh-full-view-0.1.4.tgz
   ```

3. 在已安装列表中找到 **`@yfwu2020/dsh-full-view`**，打开开关。
4. 回到会话，打开一个右侧文件或浏览器面板，点击面板上的 **全屏**。

![Harness 插件管理页：在列表底部找到 @yfwu2020/dsh-full-view](https://raw.githubusercontent.com/yfwu2020/dsh-full-view/main/docs/images/plugin-manager.png)

图中的插件开关处于关闭状态。安装后请将这一行的开关打开，再进入右侧面板的「全屏」。

也可以在「添加插件」中填写指定版本的源码地址：

```text
github:yfwu2020/dsh-full-view#v0.1.4
```

仓库和安装包都带有构建好的插件文件，使用者不需要自行编译。如果 GitHub 直链无法访问，可以先从 [Releases](https://github.com/yfwu2020/dsh-full-view/releases/latest) 下载 `.tgz`，解压后在「添加插件」中填写包含插件 `package.json` 的目录绝对路径。

### 兼容范围

已在 **macOS Desktop** 上验证，内置的 `dsh-client-ui-layout` 和 `dsh-client-ui-sidebar-right` 版本为 **0.2.0-rc.2**。需要宿主提供新版右面板及完整视图布局。

旧版 Harness，以及旧源码中使用 `details` 布局的界面，暂未支持。其他系统和其他版本尚未完成完整验证。

## 怎么用

### 1. 先打开右侧面板

正常状态下，聊天和文件或网页预览并排显示。先在 Harness 中打开需要查看的文件或网页，再点击右面板的 **全屏**。

![分栏视图：聊天在中间，网页预览在右侧，输入框中保留着草稿](https://raw.githubusercontent.com/yfwu2020/dsh-full-view/main/docs/images/split-view.jpg)

### 2. 在完整视图里继续聊天

进入完整视图后，预览占据主工作区，右下角默认只显示约 48px 高的紧凑输入条。附件、权限、模型和发送按钮继续使用 Harness 原有控件。多行草稿、附件或必要提示可让输入条自动增高。点击外缘展开后，显示聊天内容和标题栏。左侧导航若已展开，会继续保留。输入框中原有的草稿继续保留，可以接着编辑和发送。

![完整视图中的聊天小窗：顶部标题栏和底部输入框](https://raw.githubusercontent.com/yfwu2020/dsh-full-view/main/docs/images/full-view.jpg)

截图来自 0.1.1，用于说明预览与聊天的位置关系。0.1.4 已改为单行胶囊输入框，右下角无角标。

| 小窗上的位置 | 操作 | 结果 |
| --- | --- | --- |
| 紧凑输入条上边缘中间的小横条（main） | 单击或键盘 Enter / 空格 | 连续缩入鲸鱼球；点击球恢复完整小窗 |
| 输入条或小窗外缘 | 单击 | 展开聊天或收起为输入条 |
| 输入条或小窗外缘 | 按住并拖动 | 移动位置，拖动不会触发切换 |
| 展开后的顶部标题栏 | 按住并拖动 | 移动聊天小窗；main 中单击不切换形态 |
| 紧凑输入条（main） | 闲置 90 秒（1 分 30 秒） | 自动收成鲸鱼球；点击小球恢复完整小窗 |
| 右下角 | 按住并拖动 | 调整小窗大小 |
| 右下角 | 双击 | 恢复默认尺寸，保留当前位置 |
| 标题栏减号 | 点击 | main：隐藏小窗，保留恢复入口；0.1.4：收起为输入条 |
| 标题栏分栏图标 | 点击 | 退出完整视图，回到分栏 |
| 顶部标题栏 | 双击 | 恢复默认尺寸和右下角位置 |

展开后的聊天小窗默认宽 **400px**、高 **540px**，会根据可见工作区限制尺寸。默认会记住你调整后的位置和大小。

右下角不显示角标，将鼠标移到那里可拖动缩放；双击则恢复默认尺寸。若已自定义初始尺寸，会恢复为该配置。空间不足时会自动限制尺寸，并调整位置以保持小窗可见。

### 3. 需要更多空间时，收起聊天

单击小窗最外侧的边缘，即可收起为紧凑输入条，草稿和后台回复保留。主分支中点击或键盘聚焦输入框会直接展开完整小窗，点击外缘也可以展开。输入框底部的统计数字在完整视图中始终隐藏。已发布的 0.1.4 则仍保持点击输入区不切换，展开后显示下方统计。

已发布的 0.1.4 也可用标题栏减号收成输入条。主分支中「−」改为隐藏整个小窗，紧凑输入条可以点击上边缘中间的小横条主动收成鲸鱼球，闲置 90 秒（1 分 30 秒）也会自动回收。点击小球即可恢复完整小窗；标题用于拖动位置，外缘负责展开、收起。

旧版收起状态如下。0.1.4 已改为可继续输入的紧凑输入条。

![0.1.1 的收起状态：工作区保持展开，聊天小窗只保留一条标题栏](https://raw.githubusercontent.com/yfwu2020/dsh-full-view/main/docs/images/collapsed-chat.jpg)

### 4. 回到原来的分栏

点击小窗的 **分栏图标**，或者右面板原有的 **退出全屏**。聊天回到原位置，已有草稿、文件和网页内容继续保留。插件切换布局时不会主动重新加载网页。

使用键盘时，将焦点移到外缘切换按钮后，按 `Enter` 或空格可展开、收起。展开后可将焦点移到小窗右下角的调整大小手柄，再用方向键改变尺寸；按住 `Shift` 可加大步长。已发布的 0.1.4 不另外注册 `Esc`；主分支新增的 Esc 仅在聊天内生效，并让原生菜单和输入法优先处理。

## 关闭和卸载

**暂时不用**：在 Harness 的插件管理页关闭 `@yfwu2020/dsh-full-view` 的开关。悬浮聊天扩展会停止，面板恢复宿主的显示方式。关闭插件与退出面板全屏是两个独立操作。

**彻底移除**：打开这个插件的详情，在管理页中卸载。当前版本的启用与停用统一跟随 Harness 的插件开关。

如果你是用仓库中的本地安装脚本安装的，也可以在插件目录执行：

```sh
node scripts/uninstall-local.mjs desktop
```

这个脚本删除对应的本地依赖、启用选择和链接，保留其他插件的设置。

## 常见问题

**已经安装，为什么没有小窗？**

确认插件开关已打开，并且已经进入右侧文件或浏览器面板的「全屏」。普通分栏时不会出现小窗。如果安装后界面尚未加载新插件，重新打开 Harness。仍无效时，请检查上述版本兼容范围。

**我关闭了插件，面板为什么还在全屏？**

插件开关控制悬浮聊天功能；面板的全屏状态由 Harness 自己管理。点击面板的「退出全屏」即可回到分栏。

**开关显示关闭，但小窗仍在，怎么办？**

0.1.1 修复了初版本地安装脚本导致的启停不一致。通过管理页安装的用户可更新到 0.1.1。如果曾用 0.1.0 的 `scripts/install-local.mjs` 安装，请先将 0.1.1 文件更新到原来的本地插件目录，保持目录路径不变，再在该目录重新运行：

```sh
node scripts/install-local.mjs desktop
```

脚本会迁移旧的直接加载条目，保留你当前的开关选择，并备份修改前的配置。迁移后重新检查管理页和界面。

**会保存我的聊天或网页内容吗？**

插件自身只记住小窗的位置和尺寸，不另外保存或上传会话、草稿及网页内容。原会话的数据处理和存储继续由 Harness 管理。

**左侧栏收起后，为什么没有图标竖条？**

当前已验证的 macOS Desktop 版本会将收起后的左侧栏完全隐藏，展开入口移到窗口左上方。这是宿主的布局行为；本插件不修改该逻辑。

**如何反馈兼容问题？**

请在 [Issues](https://github.com/yfwu2020/dsh-full-view/issues) 中说明系统、Harness 版本、是否已开启右侧全屏、复现步骤，并附上能说明布局问题的截图。截图前请遮盖私人会话和敏感内容。
