# 完整视图 · 悬浮聊天

**把空间留给文件和网页，同时继续和 Agent 对话。**

这是 DeepSeek Harness 的界面插件。点击右侧文件或浏览器面板的「全屏」，工作内容展开到主工作区，当前聊天变成右下角的小窗。你可以一边看预览、一边继续发消息；退出全屏后，聊天回到原来的分栏位置。

[下载安装包](https://github.com/yfwu2020/dsh-full-view/releases/latest) · [报告问题](https://github.com/yfwu2020/dsh-full-view/issues) · [更新记录](#更新记录)

![完整视图：网页占据主工作区，原聊天保留在右下角小窗中](https://raw.githubusercontent.com/yfwu2020/dsh-full-view/main/docs/images/full-view.jpg)

> 本文配图均为 DeepSeek Harness 实际界面截图。操作截图在 macOS Desktop 中运行本插件，使用公开示例网页展示分栏、聊天小窗和收起状态；为避免展示其他会话，截图时收起了左侧导航。

## 它能做什么

- **展开工作内容**：让右侧文件、编辑器或网页预览获得更大的显示空间。
- **继续原来的对话**：小窗使用当前会话，保留消息、输入草稿和宿主的聊天操作。
- **移动与调整大小**：拖动标题栏移动，拖动右下角调整尺寸。
- **临时收起聊天**：只留一条标题栏，需要时再展开。
- **一键回到分栏**：聊天、文件和网页继续使用原来的内容实例。

这个插件只改变完整视图中的呈现方式。左侧导航栏的展开与收起仍由 Harness 管理。

## 安装

### 通过 Harness 插件管理页安装

1. 打开 Harness 左侧的 **插件** 页面，点击 **添加插件**。
2. 填写 npm 包名，完成安装：

   ```text
   @yfwu2020/dsh-full-view
   ```

   需要固定版本时填写 `@yfwu2020/dsh-full-view@0.1.1`。也可以使用 GitHub 上的 0.1.1 安装包地址：

   ```text
   https://github.com/yfwu2020/dsh-full-view/releases/download/v0.1.1/yfwu2020-dsh-full-view-0.1.1.tgz
   ```

3. 在已安装列表中找到 **`@yfwu2020/dsh-full-view`**，打开开关。
4. 回到会话，打开一个右侧文件或浏览器面板，点击面板上的 **全屏**。

![Harness 插件管理页：在列表底部找到 @yfwu2020/dsh-full-view](https://raw.githubusercontent.com/yfwu2020/dsh-full-view/main/docs/images/plugin-manager.png)

图中的插件开关处于关闭状态。安装后请将这一行的开关打开，再进入右侧面板的「全屏」。

也可以在「添加插件」中填写指定版本的源码地址：

```text
github:yfwu2020/dsh-full-view#v0.1.1
```

仓库和安装包都带有构建好的插件文件，使用者不需要自行编译。如果 GitHub 直链无法访问，可以先从 [Releases](https://github.com/yfwu2020/dsh-full-view/releases/latest) 下载 `.tgz`，解压后在「添加插件」中填写包含插件 `package.json` 的目录绝对路径。

### 兼容范围

已在 **macOS Desktop** 上验证，内置的 `dsh-client-ui-layout` 和 `dsh-client-ui-sidebar-right` 版本为 **0.2.0-rc.2**。需要宿主提供新版右面板及完整视图布局。

旧版 Harness，以及旧源码中使用 `details` 布局的界面，暂未支持。其他系统和其他版本尚未完成完整验证。

## 怎么用

### 1. 先打开右侧面板

正常状态下，聊天和文件或网页预览并排显示。先在 Harness 中打开需要查看的文件或网页，再点击右面板的 **全屏**。

![分栏视图：聊天在中间，网页预览在右侧，输入框中保留着草稿](https://raw.githubusercontent.com/yfwu2020/dsh-full-view/main/docs/images/split-view.jpg)

### 2. 在完整视图里继续聊天

进入完整视图后，预览占据主工作区，当前聊天浮到右下角。左侧导航若已展开，会继续保留。输入框中原有的草稿继续保留，可以接着编辑和发送。

![完整视图中的聊天小窗：顶部标题栏、底部输入框和右下角调整大小手柄](https://raw.githubusercontent.com/yfwu2020/dsh-full-view/main/docs/images/full-view.jpg)

| 小窗上的位置 | 操作 | 结果 |
| --- | --- | --- |
| 顶部标题栏 | 按住并拖动 | 移动聊天小窗 |
| 右下角 | 按住并拖动 | 调整小窗大小 |
| 标题栏减号 | 点击 | 收起聊天，仅保留标题栏 |
| 收起后的减号按钮 | 再次点击 | 展开聊天 |
| 标题栏分栏图标 | 点击 | 退出完整视图，回到分栏 |
| 顶部标题栏 | 双击 | 恢复默认尺寸和右下角位置 |

小窗默认宽 **400px**、高 **540px**，会根据可见工作区限制尺寸。默认会记住你调整后的位置和大小。

### 3. 需要更多空间时，收起聊天

点击标题栏上的减号，小窗收成一条细标题栏。对话内容和输入草稿仍然保留；再次点击即可继续聊天。

![收起聊天：工作区保持展开，聊天小窗只保留一条标题栏](https://raw.githubusercontent.com/yfwu2020/dsh-full-view/main/docs/images/collapsed-chat.jpg)

### 4. 回到原来的分栏

点击小窗的 **分栏图标**，或者右面板原有的 **退出全屏**。聊天回到原位置，已有草稿、文件和网页内容继续保留。插件切换布局时不会主动重新加载网页。

使用键盘时，可将焦点移到小窗右下角的调整大小手柄，再用方向键改变尺寸；按住 `Shift` 可加大步长。插件不另外注册 `Esc`，避免与宿主操作冲突。

## 关闭和卸载

**暂时不用**：在 Harness 的插件管理页关闭 `@yfwu2020/dsh-full-view` 的开关。悬浮聊天扩展会停止，面板恢复宿主的显示方式。关闭插件与退出面板全屏是两个独立操作。

**彻底移除**：打开这个插件的详情，在管理页中卸载。当前版本的启用与停用统一跟随 Harness 的插件开关。

如果你是用仓库中的本地安装脚本安装的，也可以在插件目录执行：

```sh
node scripts/uninstall-local.mjs desktop
```

这个脚本删除对应的本地依赖、启用选择和链接，保留其他插件的设置。

## 常见问题

**已经安装，为什么没有小窗？**

确认插件开关已打开，并且已经进入右侧文件或浏览器面板的「全屏」。普通分栏时不会出现小窗。如果安装后界面尚未加载新插件，重新打开 Harness。仍无效时，请检查上述版本兼容范围。

**我关闭了插件，面板为什么还在全屏？**

插件开关控制悬浮聊天功能；面板的全屏状态由 Harness 自己管理。点击面板的「退出全屏」即可回到分栏。

**开关显示关闭，但小窗仍在，怎么办？**

0.1.1 修复了初版本地安装脚本导致的启停不一致。通过管理页安装的用户可更新到 0.1.1。如果曾用 0.1.0 的 `scripts/install-local.mjs` 安装，请先将 0.1.1 文件更新到原来的本地插件目录，保持目录路径不变，再在该目录重新运行：

```sh
node scripts/install-local.mjs desktop
```

脚本会迁移旧的直接加载条目，保留你当前的开关选择，并备份修改前的配置。迁移后重新检查管理页和界面。

**会保存我的聊天或网页内容吗？**

插件自身只记住小窗的位置和尺寸，不另外保存或上传会话、草稿及网页内容。原会话的数据处理和存储继续由 Harness 管理。

**左侧栏收起后，为什么没有图标竖条？**

当前已验证的 macOS Desktop 版本会将收起后的左侧栏完全隐藏，展开入口移到窗口左上方。这是宿主的布局行为；本插件不修改该逻辑。

**如何反馈兼容问题？**

请在 [Issues](https://github.com/yfwu2020/dsh-full-view/issues) 中说明系统、Harness 版本、是否已开启右侧全屏、复现步骤，并附上能说明布局问题的截图。截图前请遮盖私人会话和敏感内容。

## 开发与本地演示

开发和测试使用 Node.js 24。

```sh
npm ci --ignore-scripts --legacy-peer-deps
npm run check
node scripts/preview.mjs
```

打开 `http://127.0.0.1:4198` 即可体验用于开发验证的独立演示页。它直接加载构建好的插件，演示消息不会发送给模型。演示服务器只监听本机地址。

需要将源码目录链接到本机 Desktop profile 时，可执行 `node scripts/install-local.mjs desktop`。首次安装会启用，重复执行会保留管理页的选择。使用 Harness CLI 安装 Desktop 插件时，请遵守 CLI 对退出应用的提示。

尺寸配置、实现边界和验证记录见 [技术说明](docs/technical.md) 与 [验证记录](VALIDATION.md)。

维护者发布新版本时，请参阅 [发布指南](docs/releasing.md)。正式 GitHub Release 会触发 npm 发布；普通提交只运行检查。
