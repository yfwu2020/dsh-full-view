# 配置和适配说明

普通使用者无需修改以下配置。通过 Harness 的标准 bundle 机制加载插件；管理页的启停选择是插件是否加载的依据。

## 配置

| 字段 | 默认 | 范围 / 含义 |
| --- | --- | --- |
| chatWidth | 400 | 280–800，初始宽度，像素 |
| chatHeight | 540 | 240–1000，初始高度，像素 |
| edgeGap | 20 | 0–64，与工作区边缘的间隔，像素 |
| rememberGeometry | true | 在浏览器 localStorage 中记录窗口几何信息 |
| compactIdleSeconds | 30 | 0–3600，紧凑条闲置回收秒数；0 关闭自动回收 |

实际尺寸限制在可见工作区内。记录的几何信息会优先于初始尺寸；双击右下角可恢复配置尺寸并保留当前位置，双击标题栏可恢复配置尺寸和默认位置。若当前位置无法容纳恢复后的尺寸，会调整位置以保持小窗可见。

配置由宿主入口校验，经 `/dsh-full-view/api/config` 传给客户端。非法配置在加载时拒绝。插件卸载后移除该路由。

## 适配范围

宿主加载 `lib/index.js`，客户端通过 `window.__ModuleLoader__` 加载 `lib/client.js`。客户端依赖 `layout`、`sidebarRight`、`sessions` 和 `uiSession` 服务。

适配器通过 `data-rightbar-col`、`data-rightbar-fullscreen`、`data-sidebar-right-panel` 等语义标记找到原聊天容器，并检查会话身份匹配。它改变原聊天容器的定位，不重建会话、编辑器或 iframe。返回分栏使用面板自身的按钮。

宿主更改上述标记或相邻结构时，需要更新适配器。目前针对 layout / sidebar-right 0.2.0-rc.2 验证；未支持旧源码中的 details 布局。

小窗层级为 50，在原工作面板之上、DockKit 原有浮窗层级 60 之下。宿主菜单及审批弹窗仍由宿主管理，尚未完成所有弹窗组合的交互验证。

卸载和热重载会清理插件的工具栏、样式、几何标记、事件与观察器，保留宿主原有内容及布局状态。

## 紧凑输入条（0.1.4）

通过 `data-composer-seat`、`data-composer-card`、`data-input-scroll` 找到原生输入区，给控制行及其两组控件附加临时标记，用网格将其与原编辑器排成一行。模型显示图标，权限文字收成图标，按钮原有 aria-label 和菜单保留。没有复制编辑器或转发输入事件。

进入完整视图默认收起，隐藏消息、标题栏及输入框下方详情，保留输入区、附件与必要提示。观察输入区实际高度，空输入条至少 48px；多行文本和附件自动增高。展开与收起保持底部位置，移动保存展开尺寸所对应的位置。

透明外缘按钮只有约 6px 的四边接收指针事件，中间区域让原编辑器和按钮正常操作。移动超过 4px 按拖动处理，随后点击不切换；键盘 Enter / 空格仍使用原生按钮行为。展开后右下角保留独立的缩放区域。

宿主替换输入框节点时重新附加标记，退出或卸载删除全部临时标记。未提供上述输入区标记的宿主回退到原有标题栏收起方式。

## main 分支新增适配（尚未发布）

交互采用紧凑、展开、隐藏三种状态，操作栏显示与消息区展开是两个独立条件。鲸鱼恢复入口附着在工作区，避免被原聊天的 inert 隔离。缩放与移动共用受约束的几何计算；鼠标取消恢复起始偏好，视口变化只限制呈现，不写回偏好。

标题只负责移动：按住拖动或用方向键调整位置，单击不改变形态；外缘切换紧凑 / 展开；左上角「−」始终隐藏整个小窗，保留恢复入口。减号的辅助名称及悬停提示都表示隐藏，不再使用 aria-expanded。

主操作图标使用统一的 18px 尺寸，权限图标的包裹元素同步调整，模型脑形 mask 复用同一个尺寸变量，下拉箭头保留宿主的较小尺寸。移除 pointerenter / pointerleave 标题栏触发。用户 focusin 或再次 pointerdown 原编辑器直接进入 expanded；程序归还焦点用同步保护避免收起后反复展开。标题栏只在完整小窗中显示，不增加紧凑高度。

紧凑输入路径的宿主背景设为透明，避免原会话的方形白底覆盖外框圆角；不通过 overflow:hidden 裁切菜单。模型按钮的原 SVG 仅以临时属性隐藏，使用 currentColor 的脑形 SVG mask 显示替代图标，保留原按钮、下拉箭头和事件。宿主重绘按钮时重新适配，退出或卸载移除临时属性并恢复原图标。

只适配当前顶层会话的 composer，排除内嵌子会话。审批、提问、计划确认的原生标记触发展开；轨迹视图的 overlay 标记不参与待办判定。原输入区被替换时优先展示替代组件。退出与停用还原原有辅助属性，移除视觉视口监听和未完成的点击计时器。

具体行为、参考依据和无法现场验证的边界见 [交互设计说明](interaction-design.md)。

## 运行状态与鲸鱼入口（main，尚未发布）

读取 `uiSession.sessionStatus` 的当前会话 running / pendingInteraction，借用 `sessions.binding(id)`，不延长会话生命周期。订阅该 binding 的 session 与 eventSource，取最后一个 `turn/start` 的 event.time；已有匹配 `turn/end` 的旧回合不能成为下一回合的计时起点。缺失起始记录时显示“处理中…”。

在原 `data-input-scroll` 内按占位文字位置覆盖低对比度耗时，与按钮同一行，不增加卡片高度，不复制原编辑器、不弹出新内容通知。只有当前会话正在运行、没有待办且输入为空时显示；输入草稿时让出位置，清空后重新显示。完成、等待确认或退出完整视图停止秒级计时。切换会话或 binding 代际会释放旧订阅；停用释放所有订阅及计时器。不存储会话内容。

40px 圆形恢复按钮只显示 Harness 原生鲸鱼尾巴，无可见文字及悬停标题，辅助名称保留“恢复聊天”。运行时读取已安装宿主 `ChatView.module.css` 样式中的 APNG mask，直接使用原生动画；空闲时去除 APNG 动画块，保留第一帧及原 CRC，显示相同图形的静止状态。遵从 prefers-reduced-motion 和 forced-colors，恢复和拖动继续使用原交互。插件不打包宿主品牌图片；该适配依赖当前已验证版本的样式标记与 mask 格式，宿主改变格式时需更新适配。

## 聚焦展开、隐藏统计与形态过渡（main，尚未发布）

`data-dsh-full-view-input-footer` 在整个浮窗状态下隐藏，退出或卸载后标记移除，普通分栏的原统计恢复。聚焦或点击当前顶层会话的原编辑器直接展开；原生菜单和输入法仍由现有保护逻辑处理。隐藏入口恢复时直接进入 expanded。

用 CSS transition 在 280ms 内同步顶部位置与高度，保持底部锚点；圆角 240ms，标题 opacity / discrete display 160ms。紧凑输入路径固定在浮窗底部，减少形态变化时的输入位置跳动。隐藏面板通过 opacity、轻微 transform 与 visibility 过渡，交互状态立即 inert；鲸鱼入口反向淡入 / 淡出。CSS 负责中途反向衔接，没有延后写入旧状态的动画计时器。拖动禁用过渡以立即跟随，系统 prefers-reduced-motion 下关闭全部形态动画。

## 紧凑条闲置回收

只在具备原生输入区的 compact 状态设置一次性计时器，默认 30 秒。用户在原聊天内的 pointerdown / pointermove / keydown / wheel / input 重新计时；流式 DOM 变化和任务状态订阅只维持当前截止时间。展开、隐藏、菜单、拖动、中文组合输入及审批 / 提问 / 计划确认取消计时，恢复可回收状态后重新开始完整周期。到期再次检查当前状态，调用原隐藏过渡并保留工作区焦点，鲸鱼图形继续读取真实任务状态。退出、卸载和会话切换清理计时及 IME 状态；0 禁用回收。标题与工具栏空白不注册单击切换，标题仍支持拖动、键盘移动及双击复位。

## 浮窗滚动条与输入框对齐

宿主 `[data-conversation-scroll]` 同时包含消息和 composer，原样式有 `scrollbar-gutter: stable` 和 2px 右边距。紧凑形态的输入路径使用全宽定位，会释放这块预留空间，导致展开 / 收起时输入框宽度变化。浮窗标记范围内，聊天及 `[data-input-scroll]` 使用 `scrollbar-width: none`、`scrollbar-gutter: auto` 和零尺寸 WebKit 滚动条；聊天滚动容器右边距改为 0。保留宿主 overflow 和原滚动节点，滚动与长草稿编辑仍由 Harness 处理。退出完整视图或卸载后覆盖失效，分栏恢复宿主滚动条与间距。


### 鲸鱼球状态

通过宿主 `uiSession.sessionStatus` 读取运行、`pendingInteraction.kind` 和完成提醒；等待回应优先于运行，运行优先于完成，最后为空闲。标题在当前主会话被保留时会清除 `completionUnread`，因此同时核对最新匹配的 `turn/start` / `turn/end`，使当前球形状态仍可显示已完成。新的运行和切换会话不会继承之前的完成状态。

6px 小点位于 40px 球内的 top/right 7px。颜色直接引用原生 StateDot 的 `--dsw-alias-label-tertiary`（ongoing）、`--dsw-alias-state-success-primary`（done）、`--dsw-alias-state-warn-primary`（warning）、`--dsw-alias-state-idle-primary`（idle）。状态点不拦截鼠标，不显示文字或悬停标题，辅助标签区分等待回答、审批和计划确认。

原本隐藏的会话出现待办时保留鲸鱼球；点击恢复展开原控件，并优先聚焦待办的输入控件或操作按钮。紧凑条遇到待办仍展开。已展开待办处理前禁止再次隐藏，处理后恢复原形态。显示时 visibility 立即生效，隐藏时延迟至淡出结束，避免动画开始时拒绝输入焦点。


### 连续缩入与反向恢复

`src/client/morph.js` 实现用户选定的「连续缩入」；440ms，采用与独立预览一致的三次缓出。收起时前 24% 淡出内容，7% 后开始外框尺寸和位置插值，65% 后显示原鲸鱼球。恢复时鱼尾先淡出，外框展开，后 24% 恢复内容和输入焦点。

外框为插件拥有的空装饰层，不复制消息、不重建编辑器，也不重新挂载原聊天。内容保持原宽高，以平移和裁切跟随外框，所以文字不会压缩或重排。隐藏保留原来的紧凑 / 完整呈现形态，只改变交互与可见性；原聊天立即 inert。动画结束清理所有临时属性、样式和装饰层，恢复时才归还原输入或待办焦点。

连续反向操作以当前帧的尺寸、位置和透明度为起点。工作区尺寸变化安全结束动画；切换会话直接取消旧动画，避免旧回调抢新会话焦点。自动回收不抢工作区焦点。退出完整视图、卸载或热重载取消帧回调和所有临时层。系统减少动态效果、无 matchMedia 的环境直接切换。原有高度 / 顶部过渡仅用于完整小窗与紧凑条切换，不再叠加隐藏、恢复的旧淡出动画。
