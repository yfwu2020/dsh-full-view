# 配置和适配说明

普通使用者无需修改以下配置。通过 Harness 的标准 bundle 机制加载插件；管理页的启停选择是插件是否加载的依据。

## 配置

| 字段 | 默认 | 范围 / 含义 |
| --- | --- | --- |
| chatWidth | 400 | 280–800，初始宽度，像素 |
| chatHeight | 540 | 240–1000，初始高度，像素 |
| edgeGap | 20 | 0–64，与工作区边缘的间隔，像素 |
| rememberGeometry | true | 在浏览器 localStorage 中记录窗口几何信息 |

实际尺寸限制在可见工作区内。记录的几何信息会优先于初始尺寸；双击右下角可恢复配置尺寸并保留当前位置，双击标题栏可恢复配置尺寸和默认位置。若当前位置无法容纳恢复后的尺寸，会调整位置以保持小窗可见。

配置由宿主入口校验，经 `/dsh-full-view/api/config` 传给客户端。非法配置在加载时拒绝。插件卸载后移除该路由。

## 适配范围

宿主加载 `lib/index.js`，客户端通过 `window.__ModuleLoader__` 加载 `lib/client.js`。客户端依赖 `layout` 和 `sidebarRight` 服务。

适配器通过 `data-rightbar-col`、`data-rightbar-fullscreen`、`data-sidebar-right-panel` 等语义标记找到原聊天容器，并检查会话身份匹配。它改变原聊天容器的定位，不重建会话、编辑器或 iframe。返回分栏使用面板自身的按钮。

宿主更改上述标记或相邻结构时，需要更新适配器。目前针对 layout / sidebar-right 0.2.0-rc.2 验证；未支持旧源码中的 details 布局。

小窗层级为 50，在原工作面板之上、DockKit 原有浮窗层级 60 之下。宿主菜单及审批弹窗仍由宿主管理，尚未完成所有弹窗组合的交互验证。

卸载和热重载会清理插件的工具栏、样式、几何标记、事件与观察器，保留宿主原有内容及布局状态。

## 紧凑输入条（0.1.4）

通过 `data-composer-seat`、`data-composer-card`、`data-input-scroll` 找到原生输入区，给控制行及其两组控件附加临时标记，用网格将其与原编辑器排成一行。模型显示图标，权限文字收成图标，按钮原有 aria-label 和菜单保留。没有复制编辑器或转发输入事件。

进入完整视图默认收起，隐藏消息、标题栏及输入框下方详情，保留输入区、附件与必要提示。观察输入区实际高度，空输入条至少 48px；多行文本和附件自动增高。展开与收起保持底部位置，移动保存展开尺寸所对应的位置。

透明外缘按钮只有约 6px 的四边接收指针事件，中间区域让原编辑器和按钮正常操作。移动超过 4px 按拖动处理，随后点击不切换；键盘 Enter / 空格仍使用原生按钮行为。展开后右下角保留独立的缩放区域。

宿主替换输入框节点时重新附加标记，退出或卸载删除全部临时标记。未提供上述输入区标记的宿主回退到原有标题栏收起方式。

## main 分支新增适配（尚未发布）

交互采用紧凑、展开、隐藏三种状态，操作栏显示与消息区展开是两个独立条件。隐藏入口和更新提示附着在工作区，避免被原聊天的 inert 隔离。缩放与移动共用受约束的几何计算；鼠标取消恢复起始偏好，视口变化只限制呈现，不写回偏好。

标题和外缘切换紧凑 / 展开；左上角「−」始终隐藏整个小窗，保留恢复入口。减号的辅助名称及悬停提示都表示隐藏，不再使用 aria-expanded。

紧凑输入路径的宿主背景设为透明，避免原会话的方形白底覆盖外框圆角；不通过 overflow:hidden 裁切菜单。模型按钮的原 SVG 仅以临时属性隐藏，使用 currentColor 的脑形 SVG mask 显示替代图标，保留原按钮、下拉箭头和事件。宿主重绘按钮时重新适配，退出或卸载移除临时属性并恢复原图标。

只适配当前顶层会话的 composer，排除内嵌子会话。审批、提问、计划确认的原生标记触发展开；轨迹视图的 overlay 标记不参与待办判定。原输入区被替换时优先展示替代组件。退出与停用还原原有辅助属性，移除视觉视口监听和未完成的点击计时器。

具体行为、参考依据和无法现场验证的边界见 [交互设计说明](interaction-design.md)。
